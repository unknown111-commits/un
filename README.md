# 文学杀

网页版、可联机的卡牌桌游。服务端持唯一状态，两个浏览器各自一座位。

## 起

```bash
node server.js          # 默认 8899
PORT=9000 node server.js
```

本机打开 <http://127.0.0.1:8899>，同一局域网里另一台设备用 `http://<本机IP>:8899`。
一方「开一局」拿到四位房间号，另一方填号「进去」。

## 目录

| 文件 | 作用 |
|---|---|
| `server.js` | 静态站点 + WebSocket 房间，只转发意图与快照 |
| `game.js` | 规则引擎（服务端权威） |
| `data/cards.json` | 卡池：角色、手牌、胜利条件 |
| `public/` | 牌桌界面 |
| `test/flow.mjs` | 端到端冒烟：建房、落座、抽牌、阅读、换手 |

## 已按规则文档落地的

- 所有适性视作护盾（角色卡上的 `traits` → `shield`，换算规则待定）
- 普攻造成攻击力 **80%** 的现实伤害
- 双方共用同一卡池；抽角色按 3 级 60% / 4 级 35% / 5 级 5%
- 场上最多阅读 4 位角色；哲学家限一位
- 每回合开始：抽 1 张角色 + 3 张手牌
- 4 级角色可返还换 1 次重抽，5 级换 2 次，每回合限一次
- 每回合开始 +3 行动值，上限 12
- 1 点行动值 = 3 张手牌，或阅读一位角色，或一次普攻
- 使用手牌与攻击都算「进行行为」（快照里保留这个状态位）
- 阅读 = 上场
